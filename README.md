# Проект "Bank Feature"

## Описание

IT-отдел крупного банка делает новую фичу для личного кабинета клиента. Это виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка

1. Клонируйте репозиторий:

git clone git@github.com:Raivo1a/bankfeature.git

## Использование

### В настоящее время реализовано несколько полезных функций для виджета:

1) Модуль main - головная функция, отвечающая за общую логику проекта, связывающая остальные функциональности между собой.
2) Модуль masks - функция маскировки номера банковской карты и счета пользователя.
2) Модуль widget - функция маски номера карты или счета, а также функция форматирования даты и приведения её к виду "ДД.ММ.ГГГГ".
3) Модуль processing содержит функции по работе с банковскими операциями пользователя: функция фильтрации операций по статусу "Исполненная" и "Отмененная", а также функция сортировки банковских операций по дате проведения.
