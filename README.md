# Проект "Bank Feature"

## Описание

IT-отдел крупного банка делает новую фичу для личного кабинета клиента. Это виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка

1. Клонируйте репозиторий:

git clone git@github.com:Raivo1a/bankfeature.git

## Использование

### В настоящее время реализовано несколько полезных функций для виджета:

1) Модуль main - головная функция, отвечающая за общую логику проекта, связывающая остальные функциональности между собой.
2) Модуль masks - функция маскировки номера банковской карты и счета пользователя.
2) Модуль widget - функция маски номера карты или счета, а также функция форматирования даты и приведения её к виду "ДД.ММ.ГГГГ".
3) Модуль processing содержит функции по работе с банковскими операциями пользователя: функция фильтрации операций по статусу "Исполненная" и "Отмененная", а также функция сортировки банковских операций по дате проведения.
4) Модуль generators содержит функции: выдача транзакций, где валюта операции соответствует заданной (например, USD); выдает описание каждой операции по очереди; сгенерирует номера карт в заданном диапазоне.
5) Модуль decorators содержит декоратор, который будет автоматически логировать начало и конец выполнения функции, а также ее результаты или возникшие ошибки.
6) Модуль utils дает возможность получить информацию по банковским операциям из JSON-файла.
7) Модуль external_api содержит функцию, принимающая данные о транзакции и возвращающая сумму операции в рублях. Конвертирование суммы из иностранной валюты в рубли происходит по текущему курсу.
8) Модуль reader дает возможность получить информацию по банковским операциям из csv-файла и excel-файла.

## Тестирование

### Модуль masks

#### Функция get_mask_card_number:

* Правильность маскирования номера карты.
Параметризованные тесты для проверки работы функции на различных входных форматах номеров карт.
Обработка исключения ValueError при случаях, когда номер карты введен некорректно или имеет неправильную длину, нулевое или строчное (буквенное) значение.

#### Функция get_mask_account:

* Проверка правильности маскирования номера счета.
Тестирование с помощью параметризации работы функции с различными форматами и длинами номеров счетов.
Обработка исключения ValueError при случаях, когда длина счета меньше ожидаемой длины, а также при введении нулевого или строчного (буквенного) значений.

### Модуль widget

#### Функция mask_account_card:

* Проверка, что функция корректно распознает и применяет нужный тип маскировки в зависимости от типа входных данных (карта или счет).
Параметризованные тесты с разными типами карт и счетов для проверки универсальности функции.
Обработка исключения ValueError при случаях, когда функция получает пустую или некорректную для неё строку для обработки.

#### Функция get_data:

* Проверка правильности преобразования даты.
Тестирование с помощью параметризации работы функции на различных входных форматах даты.

### Модуль processing

#### Функция filter_by_state:

* Тестирование фильтрации списка словарей по заданному ключу state
Параметризация тестов, а также использование фикстур для проверки различных возможных значений статуса state.

#### Функция sort_by_date:

* Тестирование сортировки списка словарей по датам в порядке убывания и возрастания.

### Модуль generators

#### Функция filter_by_currency:

* Проверка, что функция корректно фильтрует транзакции по заданной валюте

#### Функция transaction_descriptions:

* Проверка, что функция выдает верные описания транзакций

#### Функция card_number_generator:

* Тестирование генерации номера карт в заданном диапазоне

### Модуль decorators

#### Функция log:

* Тестирование успешного выполнение функций и обработку ошибок

### Модуль utils

#### Функция get_operations_data:

* Тестирование успешного принятия данных из json файла и возврат корректных данных

### Модуль external_api

#### Функция get_transaction_amount:

* Тестирование конвертации валюты

### Модуль reader

#### Функция read_csv_file:

* Тестирование успешного принятия данных из csv файла и возврат корректных данных

#### Функция read_xlsx_file:

* Тестирование успешного принятия данных из excel файла и возврат корректных данных
